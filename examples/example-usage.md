# PC Assistant Usage Examples

## Chat with ARIA

### Example 1: System Information
```
User: "Comment va mon système?"
ARIA: "Votre CPU est à 45%, la mémoire à 62%, et le disque à 38%."
```

### Example 2: File Search
```
User: "Trouve-moi tous les fichiers PDF"
ARIA: "J'ai trouvé 23 fichiers PDF. Les plus volumineux sont..."
```

### Example 3: Process Management
```
User: "Quels programmes consomment le plus de mémoire?"
ARIA: "Les 3 programmes gourmands sont..."
```

## Voice Commands

1. Press Ctrl+Space to activate voice
2. Speak your command
3. ARIA responds with audio

## File Management

- Browse directories
- Search by name
- View metadata
- Quick access to recent files

## Configuration

Edit settings in the config panel:
- Change ARIA's name
- Set language preference
- Enable/disable features
- Adjust monitoring intervals
